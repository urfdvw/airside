# Fallback decoder samples

Short files for checking the libav.js fallback decoder. They are also decoded by `npm test`.

- `tone-alac.m4a`: ALAC in MP4, 5 s, 44.1 kHz stereo (440 Hz left, 660 Hz right). Encoded with FFmpeg.
- `tone.ape`: Monkey's Audio, the same tone. Encoded with the `mac` command-line tool (Monkey's Audio 3.99, `-c2000`).
- `tone.wv`: WavPack, the same tone. Encoded with FFmpeg.
- `tone-wmav2.wma`: WMA v2 at 128 kbps in ASF, the same tone. Encoded with FFmpeg.
- `tone-dsd64.dsf` and `tone-dsd64.dff`: DSD64 (2.8224 MHz) stereo, 2 s of tones. Generated by `node scripts/make-dsd-samples.mjs samples`.
- `silence-44-s.tak`: TAK, 3.7 s of near-silence at 44.1 kHz stereo. No TAK encoder runs on Linux, so this is the `tests/data/silence-44-s.tak` file from the [Mutagen](https://github.com/quodlibet/mutagen) test suite. It checks that TAK decodes, seeks and shows progress, but you will not hear anything. Use a TAK file of your own for a listening test.
